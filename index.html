About Me

Saya adalah mahasiswa Computer Science dengan spesialisasi pada Backend Engineering. Fokus utama saya terletak pada perancangan arsitektur server yang efisien, pengembangan RESTful API yang handal, serta manajemen database, sembari mempertahankan pemahaman yang solid mengenai integrasi Frontend.

Portofolio saya mencakup implementasi logika sistem yang kompleks, seperti pada proyek AI Drowsiness Detector. Proyek ini mendemonstrasikan kemampuan saya dalam menjembatani model Machine Learning dengan aplikasi web yang fungsional dan responsif secara real-time.

Saya berdedikasi untuk membangun infrastruktur backend yang scalable dan aman, serta selalu antusias mengeksplorasi teknologi baru untuk menciptakan ekosistem aplikasi yang berkinerja tinggi.
